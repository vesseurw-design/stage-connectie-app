ℹ️ Hoe werkt een demo-toegangscode?

Wanneer je een code aanmaakt, kunnen potentiële scholen of werkgevers deze invullen op stageconnectie.nl (of direct via een link). Na afloop van de gekozen datum verloopt de code automatisch en wordt de toegang direct geblokkeerd.
